NAS Recovery Backup

A personal tool for keeping encrypted recovery copies of selected files in the account owner’s Google Drive.

The owner runs the backup software on their own equipment. It transfers encrypted backup data to Drive, checks existing copies, and retrieves them when recovery is needed.

Why Google Drive access is requested

The tool uses rclone to list, read, create, update, and remove backup files as part of copying, checking, restoring, and retaining backups. It needs access to an existing backup repository, including files created before this OAuth client was configured.

The requested Drive permission is broad, but the backup configuration targets the owner’s designated backup folder. The backup tool does not request Gmail access.

For the owner’s use

This is a personal utility. This website provides information only; it does not offer account registration, Google sign-in, file uploads, or access to backups.
