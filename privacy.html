Privacy policy

This policy describes NAS Recovery Backup, a personal backup utility operated by its account owner, and this informational website.

Data accessed and purpose

The utility uses Google Drive authorization to access file and folder metadata and backup file contents. It lists and reads existing backup data and creates, updates, or deletes backup files to perform transfers, integrity checks, restores, and retention management.

It requests full Drive access because it must work with an existing backup repository. Its configured operations target the designated backup folder. It does not request Gmail access or use Google data for advertising, sale, or training AI models.

Storage and protection

Selected source data is encrypted by the backup software before upload to Google Drive. The owner’s equipment handles encryption and recovery. OAuth credentials and tokens are stored in local configuration and may be included in encrypted recovery copies. Backup contents and credentials are not published on this website.

Sharing

Google processes the Drive API requests and stores the encrypted backup files. The utility does not sell Google user data or share it with advertisers. The owner may keep additional encrypted recovery copies on storage they control.

Retention, deletion, and revocation

Backup copies are kept according to the owner’s configured retention rules; some recovery archives may be retained until the owner removes them. The owner can delete backup data from Drive and other backup destinations independently.

Access can be revoked through Google Account connections. Revoking access stops the utility from making authorized requests once the authorization is invalid, but does not itself delete existing backup copies. Local credentials can also be removed from the backup configuration.

This website

This static site has no forms, analytics scripts, advertising, or application cookies. GitHub Pages hosts it and may collect technical request information, such as IP addresses, under the GitHub Privacy Statement.
